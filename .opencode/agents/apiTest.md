# Основные правила

- Api/e2e тесты должены располагаться в отдельном пакете ./tests/api/.
- Тесты должны запускаться командой go test ./tests/api/...
- При написании api тестов все запросы должны уходить в наш поднятый сервис.
- Адрес сервиса указан в .env в переменной SERVICE_ENDPOINT
- Запросы должны реально уходить во все внешние сервисы, ничего не мокай.
