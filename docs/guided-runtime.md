# Локальная интеграция АЙЗАЩИТЫ

Основной сайт: `http://127.0.0.1:3000`. Запуск: `start-main-guided.ps1` в рабочей папке задачи. Он запускает только уже существующие локальные контейнеры и собственные процессы. Импорт базы, schema push, скачивание моделей и production-команды отсутствуют.

`POST /api/chat/guided` проходит проверку сессии основного приложения, затем проверку пользователя и владельца диалога в model-gate. Старый protobuf API сохранён. Новый маршрут включается данными `APP_GUIDED_DATA_PATH`; `APP_GUIDED_STAGE_COLLECTION` указывает на отдельную локальную коллекцию навигационных профилей.

Клиент передаёт отдельный объект `guided` с `version`, `categoryId`, `stageId`, `context`. Отсутствующее поле означает, что вопрос ещё не отвечен; `true`, `false` и явно выбранный `null` сохраняются раздельно. `null` остаётся отдельным значением runtime. В исходных шести категориях действует прежний точный решатель; новые пакеты выбирают ответ по закреплённым материальным предикатам, не по равенству representative context. Неизвестные поля, чужая стадия и устаревшая версия отклоняются. Embeddings показывают варианты выбора стадии, не подтверждают факты и не выбирают окончательный ответ за пользователя.

Таблица создаётся `export-guided-runtime.mjs`. Первые шесть категорий используют существующий next-решатель: 6243 достижимых состояния и 1995 исходных ID в 48 стадиях. Если его нормализатор выводит булевый факт сам, экспорт добавляет явное уточнение. После подключения долгов, доступа к аккаунтам, УК и трудовых споров вся таблица содержит 155915 состояний, 4559 исходных ID и 80 стадий. Исходные файлы, ID и контексты сохранены. Для двух email-ответов отдельно применены пять правок формулировок; before/after и SHA находятся в digital-access-review/email-wording-changes.json. Неподдержанное сочетание не получает выдуманного ответа.

Статья передаёт только category/stage/variant как навигацию. Новый чат начинается без подтверждённых обстоятельств. Подтверждённое состояние хранится в браузере отдельно для каждого chat_id; при перезагрузке API восстанавливает кнопки без дублирования истории. На другом устройстве история доступна, но состояние уточнений нужно пройти заново. `variant_id` статьи не подменяет подтверждённые факты.

Дополнительные документы статьи перечислены в `article-document-requirements.json`. Экспорт проверяет существующий variant_id, точный template_id в реестре и ссылку на шаблон в импорте статьи. Повторный документ не создаётся. Для DPS добавлено условное ходатайство о восстановлении срока; его использование не означает, что пропуск срока уже установлен.

`refresh-project-progress.mjs` повторно проверяет принятые файлы и pins, собирает найденные статьи в существующий каталог и обновляет `category-progress.json` и `article-work-queue.json`. Это одна очередь продолжения, без запуска платных генераций. Категория с отсутствующими обязательными материалами не закрывается. Частные identities коллекторов не превращаются в production variant_id. Guarded skip не считается статьёй или закрытым покрытием.

Границы: локальная функциональная проверка не является юридической приёмкой. Состояние 18 категорий и ограничения статей показаны в отчёте. Сайт запущен в dev-режиме; перенос, загрузку и развёртывание на боевом сервере выполняет только пользователь.


Продолжение 14.10.2026: основной runtime содержит 10 категорий, 80 стадий и 4559 исходных вариантов. Для debts скомпилированы восемь стадий из принятых ответов и material-outcome правил. Явный false сохраняется в состоянии; non-constraining null ответа допускается для него только если правила и исходные строки не содержат отрицательного материального исхода. В остальных случаях нет автоматической замены. 24 новых графа подключены после проверки материальных предикатов и точных source pins. Для labor.vacation_sick 2187 противоречивых состояний не выдают ответ и объясняют, что отказ и недоплата по одному решению нельзя подтвердить одновременно. Исторические показатели остаются 95/144 и 64/144; дополнительные 24 локальные next/document связки учитываются отдельно, текущий итог 88/144.
